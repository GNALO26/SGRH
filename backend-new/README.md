# NaoHR Backend Express

Backend Node.js/Express.js de la plateforme SGRH NaoHR.
Migration du backend Laravel vers Express.js avec MongoDB.

## Prérequis

- Node.js >= 20
- MongoDB
- Redis
- Comptes Cloudinary, Firebase, Gmail OAuth2 et FedaPay

## Installation

1. Cloner le dépôt.
2. Copier `.env.example` vers `.env`.
3. Renseigner les variables d'environnement.
4. Installer les dépendances :
   ```bash
   npm install
